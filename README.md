# Barista

A little coffee shop I built. Pick a drink or a bite, make it yours, and watch the receipt update as you go. Staff can manage the menu and mark orders ready.

## Run it

With the .NET 10 SDK, run `dotnet run` and open [localhost:5045](http://localhost:5045). To set up the staff account, choose **Sign in → Staff sign-in**.

SQLite sets itself up on first launch. For a quick check, run `./scripts/smoke-test.sh` while the app is running.
